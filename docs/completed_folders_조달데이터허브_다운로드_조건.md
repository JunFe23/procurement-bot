# `completed*` 폴더 CSV — 조달데이터허브 다운로드 검색조건

연도·파일 분할만 다르고 **동일한 필터 체계**로 받은 것으로 정리함.  
근거: 각 CSV **UTF-16** 본문 위쪽의 `검색조건` / `리포트 필터` / 리포트 ID(출력일은 재출력 시각이라 참고만).

---

## 1. `completed` — 물품 계약 상세 (`*물품계약*.csv`)

| 항목 | 내용 |
|------|------|
| 리포트 | `UI-ADOXFA-184R` **물품 계약 상세내역** |
| 기간 | **계약일자(From ~ To)** 만 파일마다 설정 (연 전체 / 반기 / 분기 등으로 분할 수령) |
| 수요기관·업체·**물품분류**·세부품명·물품식별·계약번호·계약명·수요기관소재시도 | 모두 **미입력(빈 값)** |
| 리포트 필터 | **`빈 필터`** |

요약: **물품분류·기관 등 제한 없이**, 계약일자 구간만 두고 전체 물품 계약 상세를 받은 형태.

---

## 2. `completed_construction` — 공사 계약 내역 (`*공사계약내역*.csv`)

| 항목 | 내용 |
|------|------|
| 리포트 | `UI-ADOXFA-185R` **공사 계약 내역** |
| 기간 | **기준일자(From ~ To)** = 해당 연도 달력 기준 전체 구간 (샘플: `20200101` ~ `20201231`) |
| 수요기관·텍스트·업체·계약명·계약번호·최초계약여부 등 | **미입력** |
| 리포트 필터 (예시) | `"YYYYMMDD" ~ "YYYYMMDD" 사이 **계약일자**"` |

요약: **공사 공공조달분류/품목 조건 없이**, 계약일자(또는 허브가 매핑한 기준일) 기준 연간(또는 설정 구간) 전체.

---

## 3. `completed_service` — 용역 계약 업체 내역 (`*용역계약업체내역*.csv`)

| 항목 | 내용 |
|------|------|
| 리포트 | `UI-ADOXCA-001R` **용역 계약업체 내역** |
| 기간 | **기준일자(From ~ To)** = 해당 연도 `YYYY-01-01` ~ `YYYY-12-31` (샘플: 2020) |
| 하위기관 | **수요기관하위기관 미포함** |
| 리포트 필터 (샘플) | **계약납품구분** `계340001` + **조달업무영역** `일반용역`, `기술용역` + 위 기준일자 구간(동일 구간이 필터에 두 번 묶여 기술되는 형태) |

요약: 용역(일반·기술) + 해당 계약납품구분 코드로 제한, 기간은 연 단위.

## 참고

- 인코딩은 모두 **탭 구분 UTF-16** 계열; 상세 적재 스크립트는 `manual_upload.py`, `construction_upload.py`, `service_upload.py`, `specific_item_upload.py`와 주석의 `SKIP_ROWS` 등을 따름.
- `completed` 내 파일은 같은 조건이라도 **계약일자 구간만** 반기·분기 단위로 나뉜 파일이 있음 (파일명의 `_1`~`_4` 등).
